# 玩转色彩 · 网站样板

独立儿童课程站，保留色彩观察学院品牌。对应共享对话里的决定：先 GitHub，不好用再转千聊。

## 文件
- `index.html` 36 课首页，大色块，适合老人点选
- `lesson-01.html` 第一课《红色遇见黄色》文字课，视频位先空着

## 使用
用浏览器直接打开 `index.html` 即可预览。发布时把这个文件夹放到 GitHub Pages。视频不要直接塞进仓库，先贴微信视频号或其他国内可打开的链接，再请一位农村图书馆的老人用微信扫码测试。
