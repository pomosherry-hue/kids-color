# 玩转色彩 · 36个神奇的颜色实验

独立儿童课程站，保留色彩观察学院品牌（Color Observation Academy · Kids）。

## 网址

**https://pomosherry-hue.github.io/kids-color/**

`qr.png` 就是这个网址的二维码，可以直接印出来或发到微信。

## 文件
- `index.html` 36 课首页，大色块，适合老人点选；每课标「可以播放」或「待确认」
- `lesson-01.html` 到 `lesson-36.html` 每课播放页，配同名的 `.mp4` 视频和 `.jpg` 封面
- `lesson-32-bilingual.html` 第 32 课中英双语版（配 `lesson-32-en.mp4`、`lesson-32-dual.mp4` 和中英字幕 `.vtt`）
- `qr.png` 网址二维码
- `incoming/` 新课材料收件夹，用法见 `incoming/README.md`；做好的移到 `incoming/done/`

## 使用
用浏览器打开上面的网址即可。本地预览：直接打开 `index.html`。
